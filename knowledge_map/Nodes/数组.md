# 数组

> 连续内存上按下标随机访问的线性结构：读写 O(1)，中间插入删除要搬移 O(n) 个元素。

## 核心思想

数组读写下标是 O(1)，但在头部或中间插入删除要整体搬移，是 O(n)。所以 LeetCode 的「原地修改」类题目通常不真的插入删除，而是用 [[双指针]] 在 O(1) 额外空间内一次遍历，把结果直接写在原数组上。

## 常见套路

- **原地删除 / 去重**：把区间拆成两段，慢指针维护已经写好的有效前缀，快指针扫描待处理区间。例题见 [[移除元素]]、[[删除有序数组中的重复项]]
- **原地合并**：尾部有空位时从后往前写，避免覆盖未处理元素。例题见 [[合并两个有序数组]]
- **顺序可变时少搬移**：题目允许打乱顺序，通常能用相向双指针减少元素移动
- **利用有序**：数组有序时可以二分定位，也可以用差分或前后缀极值做 O(n) 一次扫描。例题见 [[判断能否形成等差数列]]

## 易错点

- **先问三个边界**：空数组、单元素、相对顺序是否必须保持
- **语言差异**：C++ / Java 的数组长度固定；Python 的 list、JS 的 Array 是动态数组，扩容是摊还 O(1)

## 本库题目

- [[移除元素]]：快慢指针原地删除
- [[删除有序数组中的重复项]]：利用有序，只和已写区间的末尾比较
- [[合并两个有序数组]]：从后往前三指针
- [[判断能否形成等差数列]]：排序后看差分，或用 min / max 推出公差
- [[数组串联]]：下标映射的模拟题
