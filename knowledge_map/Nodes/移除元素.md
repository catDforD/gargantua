# 移除元素

> 移除元素（LeetCode 27，简单）指给定数组 `nums` 与值 `val`，原地移除所有等于 `val` 的元素并返回新长度：必须原地修改且只用 O(1) 额外空间，剩下的元素相对顺序可以改变，新长度之外的内容不作要求。

## 展开

- 题面与约束（LeetCode 官方页）：`nums=[3,2,2,3], val=3` → 2（`[2,2]`）；`nums=[0,1,2,2,3,0,4,2], val=2` → 5。`0 <= nums.length <= 100`，`0 <= nums[i] <= 50`，`0 <= val <= 100`。
- 官方 topic tags：Array、Two Pointers。
- **快慢指针 O(n)**：`slow` 指向下一个待写入位置，`fast` 全数组扫描，遇到 `nums[fast] != val` 就 `nums[slow++] = nums[fast]`，返回 `slow`。空间 O(1)，且保持相对顺序。
- **相向双指针 O(n)**：左指针停在等于 `val` 的位置，右指针从末尾找一个不等于 `val` 的值覆盖过来，两指针相遇即结束。题面允许打乱顺序，所以这个版本赋值次数更少。
- 易错点：返回的是新长度 `slow`，不是 `n`；不要用 `erase` / `remove` / `filter` 这类会搬移或额外分配的实现冒充原地解法。
- 考察：手撕快慢指针后追问「顺序可以变时能否减少元素移动」，对应上面第二种解法。
