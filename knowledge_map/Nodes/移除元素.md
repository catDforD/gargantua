# 移除元素

> LeetCode 27 · 简单：原地移除数组中所有等于 `val` 的元素，返回新长度。

## 题意要点

- **输入输出**：数组 `nums` 和值 `val`，原地移除所有等于 `val` 的元素，返回新长度
- **约束**：只用 O(1) 额外空间；剩余元素的相对顺序可以改变；新长度之外的内容不作要求；`0 <= nums.length <= 100`
- **示例**：`nums=[3,2,2,3], val=3` → 2（`[2,2]`）；`nums=[0,1,2,2,3,0,4,2], val=2` → 5
- **官方标签**：Array、Two Pointers

## 关键观察

不需要真的删除，只要把要保留的元素依次写到数组前部。题目还允许打乱顺序，这就给了第二种更省赋值的写法。

## 解法

### 解法一：快慢指针（时间 O(n)，空间 O(1)）

- **做法**：`slow` 指向下一个待写入位置，`fast` 扫描全数组；遇到 `nums[fast] != val` 就 `nums[slow++] = nums[fast]`
- **返回**：`slow`；这种写法保持相对顺序

### 解法二：相向双指针（时间 O(n)，空间 O(1)）

- **做法**：左指针停在等于 `val` 的位置，右指针从末尾找一个不等于 `val` 的值覆盖过来，两指针相遇即结束
- **好处**：题目允许打乱顺序，这个版本的赋值次数更少

## 易错点

- **返回值**：返回的是新长度 `slow`，不是 `n`
- **不算原地**：`erase` / `remove` / `filter` 会搬移或额外分配，不能冒充原地解法
