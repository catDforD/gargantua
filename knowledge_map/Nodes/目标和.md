# 目标和

> LeetCode 494 · 中等：给每个数前加 `+` 或 `-`，求运算结果恰为 `target` 的表达式数目。

## 题意要点

- **输入输出**：非负整数数组 `nums` 和整数 `target`，每个元素前加 `+` 或 `-` 并全部用上，返回结果等于 `target` 的方案数
- **约束**：`1 <= nums.length <= 20`，`0 <= nums[i] <= 1000`，`0 <= sum(nums) <= 1000`，`-1000 <= target <= 1000`
- **示例**：`nums=[1,1,1,1,1], target=3` → 5；`nums=[1], target=1` → 1
- **官方标签**：Array、Dynamic Programming、Backtracking、Knapsack Problem、0-1 Knapsack

## 关键观察

设取 `+` 的子集和为 P、取 `-` 的为 N，则 `P - N = target`、`P + N = totalSum`，所以 `P = (target + totalSum) / 2`。问题变成「选一个子集，使其和恰为 P 的方案数」，也就是 0-1 背包计数。

## 解法

### 解法一：DFS / 回溯（时间 O(2ⁿ)，空间 O(n)）

- **做法**：按下标递归，每个元素分 `+nums[i]` 和 `-nums[i]` 两支，`i == n` 时判断和是否等于 `target`
- **注意**：官方注明 Python3 版本会超时

### 解法二：记忆化搜索（时间 O(n·totalSum)，空间 O(n·totalSum)）

- **做法**：用 `memo[index][currentSum]` 缓存；和可能为负，下标整体偏移 `totalSum`，表大小 `n × (2·totalSum + 1)`

### 解法三：二维 DP + 滚动数组（时间 O(n·totalSum)，空间 O(totalSum)）

- **状态**：`dp[index][sum]` 为用前 `index` 个数凑出 `sum` 的方案数
- **初始化**：`dp[0][nums[0] + totalSum] = 1`，`dp[0][-nums[0] + totalSum] += 1`
- **转移**：`dp[i][sum ± nums[i]] += dp[i-1][sum]`，答案 `dp[n-1][target + totalSum]`；`|target| > totalSum` 时直接返回 0
- **压空间**：每行只依赖上一行，压成一维，每轮生成 `next` 替换

### 解法四：0-1 背包计数（时间 O(n·P)，空间 O(P)）

- **前置条件**：`target + totalSum` 必须是非负偶数，否则答案为 0
- **递推**：`f[j] += f[j - nums[i]]`，`j` 必须倒序枚举，保证用到的是上一轮的 `f[j - nums[i]]`
- **好处**：只扫到 P，通常比扫整个和域的解法三更快

## 易错点

- **初始化要累加**：`nums[0] == 0` 时 `+0` 和 `-0` 落在同一格，第二处必须 `+=`，不能直接赋值
- **背包必须倒序**：正序会让同一个数被重复使用，变成完全背包
- **先判可行**：`|target| > totalSum`，或 `target + totalSum` 为奇数，都直接返回 0

## 扩展思考

- **能说出两种思路吗？** 先讲 DFS 回溯作为基线，O(2ⁿ)；再推出 `P = (target + totalSum) / 2`，转成 0-1 背包计数，一维倒序递推。
