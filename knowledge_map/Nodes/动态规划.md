# 动态规划

> 把问题拆成相互重叠的子问题，保存子问题的解避免重复计算的方法。

## 核心思想

动态规划要求问题有最优子结构，子问题之间互相重叠。把每个子问题的解存下来，同一个子问题只算一次，复杂度就能从指数级降到多项式级。这一点和分治不同：分治的子问题互不重叠，每个本来就只解一次。

## 常见套路

- **记忆化搜索（自顶向下）**：递归加缓存。[[目标和]] 用 `memo[index][currentSum]` 缓存，官方题解说这样 *from exponential to polynomial*
- **递推填表（自底向上）**：按顺序填 `dp` 表，[[目标和]] 的 `dp[index][sum]` 就是这种写法
- **换状态定义来降复杂度**：[[最长递增子序列]] 的 O(n²) 解法定义 `d[i]` 为以 `a[i]` 结尾的最长长度；O(n log n) 解法改成 `d[l]` 为长度 `l` 的递增子序列的最小结尾，数组变得有序，可以二分
- **滚动数组压空间**：每一行只依赖上一行时，二维表可以压成一维。[[目标和]] 把空间从 O(n·totalSum) 压到 O(totalSum)

## 易错点

- **一维 0-1 背包要倒序**：`f_j = max(f_j, f_{j-w_i} + v_i)` 中 `j` 必须倒序枚举；正序会用到本轮已更新的值，相当于允许重复选取，变成完全背包。计数型 `f[j] += f[j-w_i]` 同理
- **重合的初值要累加**：多个初始状态落到同一格时要用 `+=`，不能直接赋值。[[目标和]] 中 `nums[0] == 0` 时 `+0` 和 `-0` 落在同一格

## 本库题目

- [[最长递增子序列]]：换状态定义加二分，从 O(n²) 到 O(n log n)
- [[目标和]]：从回溯到记忆化、二维 DP、滚动数组，再到 0-1 背包计数
