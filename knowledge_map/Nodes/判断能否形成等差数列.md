# 判断能否形成等差数列

> LeetCode 1502 · 简单：判断数组重新排列后，能否让任意相邻两项之差都相等。

## 题意要点

- **输入输出**：整数数组 `arr`，返回能否重排成等差数列
- **约束**：`2 <= arr.length <= 1000`，`-10^6 <= arr[i] <= 10^6`
- **示例**：`[3,5,1]` → true（`[1,3,5]`）；`[1,2,4]` → false
- **官方标签**：Array、Sorting

## 关键观察

允许重排，所以问题等价于「排序后相邻差是否恒定」。更进一步，公差其实已经被最小值和最大值决定了：只能是 `(max - min) / (n - 1)`，不必真的排序。

## 解法

### 解法一：排序后比较差分（时间 O(n log n)）

- **做法**：排序后取 `d = arr[1] - arr[0]`，检查所有 `arr[i] - arr[i-1] == d`
- **边界**：`n <= 2` 时恒为真

### 解法二：用 min / max 推公差（时间 O(n)，空间 O(n)）

- **求公差**：先求 `min`、`max`，公差只能是 `d = (max - min) / (n - 1)`，除不尽直接返回 false
- **校验**：用哈希集合（或值域数组）把每个元素映射到 `min + k * d` 的位置，确认每个位置恰好被覆盖一次

## 易错点

- **先判整除**：`(max - min)` 不能被 `n - 1` 整除时必须提前返回，否则浮点公差比较会出错
- **重复元素**：相等的元素会映射到同一个位置，也要在这里判 false
