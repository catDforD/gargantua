# 信息熵

> 衡量随机变量不确定性的量，等于用最优编码表示它的样本所需的平均比特数。

## 为什么需要

「取值有多不确定」需要一个可计算的度量：它应该随不确定性单调增加，并且在独立事件上可加，最好还能对应「描述这些数据要花多少信息」这个物理直觉。香农熵是同时满足这些要求的唯一形式，之后所有分布之间的比较（[[交叉熵]]、[[KL 散度]]）都以它为基准。

## 核心要点

- **定义**：`H(p) = -Σ p(x)·log p(x)`，约定 `0·log 0 = 0`；log 取 2 时单位是比特，取 e 时是 nat
- **取值范围**：`p` 越接近均匀分布熵越大，均匀分布取到最大值 `log n`；取值完全确定（one-hot）时熵为 0
- **信源编码定理**：平均码长不可能低于熵，霍夫曼编码这类最优编码可以任意逼近该下界，这是「熵 = 描述数据所需最少比特」的出处
- **可加性**：独立随机变量满足 `H(X, Y) = H(X) + H(Y)`
- **条件熵与互信息**：`H(Y|X)` 是已知 `X` 后 `Y` 剩余的不确定性；`I(X; Y) = H(Y) − H(Y|X)` 是 `X` 提供的关于 `Y` 的信息量

## 容易混淆

- **信息熵 vs 交叉熵**：两者都以 `p` 加权，区别在 log 里放的分布，熵用 `p` 自己，交叉熵用模型的 `q`
- **信息熵 vs 困惑度**：语言模型的困惑度是交叉熵的指数形式（底为 2 时 `PPL = 2^H`），量纲回到「等效分支数」而不是比特
- **自信息 vs 熵**：`-log p(x)` 只是单个事件的信息量，熵是它在 `p` 下的期望，一个看点、一个看平均

## 关联

- [[交叉熵]]：把最优编码换成模型分布 `q` 之后的平均码长，等于熵加上分布差距
- [[KL 散度]]：用错误分布编码时多花的那部分比特，正好是交叉熵减熵

## 扩展思考

- **为什么 one-hot 标签的熵是 0？** 结果已经确定，不需要任何比特来描述，所以用 one-hot 标签算交叉熵时，交叉熵与 KL 散度在数值上完全相等。
- **熵能不能为负？** 不能，`p(x) ≤ 1` 保证每一项 `-p(x)·log p(x) ≥ 0`；离散分布的熵下界是 0，上界是 `log n`。
