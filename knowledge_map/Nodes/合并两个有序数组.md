# 合并两个有序数组

> LeetCode 88 · 简单：把有序的 `nums2` 原地合并进有序的 `nums1`，结果保持非递减。

## 题意要点

- **输入输出**：`nums1` 前 `m` 个是有效元素、后 `n` 个是占位，`nums2` 有 `n` 个元素；把 `nums2` 合并进 `nums1`，原地修改
- **约束**：`nums1.length == m + n`
- **示例**：`nums1=[1,2,3,0,0,0], m=3, nums2=[2,5,6], n=3` → `[1,2,2,3,5,6]`；`m=0` 时结果就是 `nums2`
- **官方标签**：Array、Two Pointers、Sorting

## 关键观察

空位在 `nums1` 的尾部。从前往后写会覆盖 `nums1` 里还没参与比较的有效元素；从后往前写，用的都是空位，就不会覆盖。指针方向取决于哪一侧留有空位，这是本题的设计点。

## 解法

### 解法一：从后往前三指针（时间 O(m + n)，空间 O(1)）

- **初始化**：`p1 = m - 1`、`p2 = n - 1`、`write = m + n - 1`
- **每轮**：把 `nums1[p1]` 和 `nums2[p2]` 中较大的写到 `nums1[write]`，对应指针和 `write` 左移
- **结束**：`nums2` 耗尽时结束，剩下的 `nums1` 前缀本来就在正确位置

### 解法二：正序归并（时间 O(m + n)，空间 O(m + n)）

- **做法**：想正着写，就得先开一个临时数组归并，再拷回 `nums1`

## 易错点

- **循环条件**：`p1 >= 0 && p2 >= 0`
- **剩余元素**：循环结束后 `nums1` 的剩余前缀不用处理，但 `nums2` 还有剩余时要整体复制过去
