# 合并两个有序数组

> 合并两个有序数组（LeetCode 88，简单）指给定非递减数组 `nums1`（前 `m` 个是有效元素，后 `n` 个是占位）和 `nums2`（`n` 个元素），把 `nums2` 合并进 `nums1` 使整体仍非递减，要求原地修改 `nums1`。

## 展开

- 题面与约束（LeetCode 官方页）：`nums1=[1,2,3,0,0,0], m=3, nums2=[2,5,6], n=3` → `[1,2,2,3,5,6]`；`m=0` 时结果就是 `nums2`。`nums1.length == m + n`。
- 官方 topic tags：Array、Two Pointers、Sorting。
- **从后往前三指针**：`p1 = m - 1`、`p2 = n - 1`、`write = m + n - 1`，每轮把较大的那个写到 `nums1[write]` 再左移；`nums2` 先耗尽时结束，剩下的 `nums1` 前缀本来就在正确位置。
- **为什么不能正着写**：正序写入会覆盖 `nums1` 中尚未参与比较的有效元素，想正序就得额外开 O(m + n) 的临时数组。指针方向取决于「哪一侧留有空位」，这是本题的设计点。
- 易错点：循环条件是 `p1 >= 0 && p2 >= 0`；循环结束后不需要再处理 `nums1` 的剩余前缀，但 `nums2` 的剩余元素需要整体复制。
- 考察：三指针方向选择，属于「原地数组搬运」家族（同族见 [[删除有序数组中的重复项]]）。
