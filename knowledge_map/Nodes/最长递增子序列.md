# 最长递增子序列

> LeetCode 300 · 中等：求数组中最长严格递增子序列的长度。

## 题意要点

- **输入输出**：整数数组 `nums`，删除若干元素、不改变剩余元素的相对顺序，求能得到的最长严格递增序列的长度
- **约束**：`1 <= nums.length <= 2500`，`-10^4 <= nums[i] <= 10^4`；进阶要求 O(n log n)
- **示例**：`[10,9,2,5,3,7,101,18]` → 4（`[2,3,7,101]`）；`[0,1,0,3,2,3]` → 4；`[7,7,7,7,7,7,7]` → 1
- **官方标签**：Array、Binary Search、Dynamic Programming，即「DP + 二分」两条路线

## 关键观察

按「以第 i 个元素结尾」定义状态，每个位置都要回看所有前驱，是 O(n²)。换一种定义，记录「每个长度的递增子序列最小能以多少结尾」，这个数组本身是有序的，于是可以二分，降到 O(n log n)。

## 解法

### 解法一：动态规划（时间 O(n²)，空间 O(n)）

- **状态**：`d[i]` 为以 `a[i]` 结尾的 LIS 长度
- **转移**：`d[i] = max(1, max{ d[j] + 1 : j < i 且 a[j] < a[i] })`，答案是 `max(d[i])`
- **还原序列**：额外记一个前驱数组 `p[]`，空间仍是 O(n)

### 解法二：贪心 + 二分（时间 O(n log n)，空间 O(n)）

- **状态**：`d[l]` 为长度 `l` 的递增子序列的最小可能结尾元素
- **两条性质**：`d` 恒严格递增；每个 `a[i]` 至多更新一个 `d[l]`
- **做法**：对每个 `a[i]` 用 `lower_bound` 找第一个 ≥ `a[i]` 的位置；越界就追加，否则覆盖。答案是 `d` 的长度

## 易错点

- **用 `lower_bound`，不是 `upper_bound`**：严格递增要找第一个 ≥ x 的位置。cp-algorithms 正文写的是「第一个严格大于」，但它的代码用的是 `lower_bound`，以代码为准。反例：`d=[-∞,3,4,6]`、`x=4`，`lower_bound` 得 l=2，覆盖后仍严格递增；`upper_bound` 得 l=3，写出 `d[2]=4, d[3]=4`，破坏了不变式。只有题目改成「非递减」时才用 `upper_bound`
- **子序列不是子串**：元素可以不连续
- **默认严格递增**：相等元素不能同时入选，全相同数组的答案是 1

## 扩展思考

- **手撕 LIS，能优化到 O(n log n) 吗？** 能。把状态换成「长度为 l 的最小结尾」，这个数组有序，每个元素用 `lower_bound` 二分定位后覆盖或追加。
