# 神经网络

> 把神经元按层堆叠、用可学习权重连接起来的函数逼近器，靠非线性激活换取表达能力。

## 为什么需要

想让计算机识别手写数字。一张 28×28 的图片有 784 个像素，我们需要一个函数，输入这 784 个数、输出 0–9 的判断。问题是，「像素值到数字」之间的映射极其复杂，没人能手写出这样的规则。神经网络的思路是：把大量可调参数（权重和偏置）堆成好几层，中间插上非线性激活函数，然后用数据把参数「训」出来。层数一多，网络自己学会了先认笔画、再认轮廓、最后认整体形状。

## 核心要点

- **一个神经元在干什么**：拿到上一层所有输出的加权和 `z = w₁a₁ + w₂a₂ + ... + b`，再过一个激活函数（比如 sigmoid 或 ReLU）输出一个数。权重决定它关注上一层的哪些信号，偏置决定它多容易被激活
- **整层写成矩阵**：一层 n 个神经元可以写成 `a = σ(W·a_prev + b)`，W 是权重矩阵，b 是偏置向量，σ 是激活函数逐元素作用
- **参数量怎么算**：两层之间是全连接的，一层 m 个到下一层 n 个就有 `m × n` 个权重加 n 个偏置。一个 784 → 16 → 16 → 10 的小网络总共 13,002 个参数
- **为什么一定要激活函数**：没有激活函数的话，不管堆多少层都等于做了一次线性变换，连「异或」这种简单关系都拟合不了。加上非线性之后，层数才真正带来表达能力
- **ReLU 为什么是主流**：sigmoid 在两端梯度接近 0，层数一多梯度就传不回去（梯度消失）。ReLU 只做 `max(0, x)`，正半轴梯度恒为 1，训练起来快得多
- **推理就是矩阵乘法**：训练好之后，输入进去逐层做矩阵乘法就出结果，没有迭代，所以能直接搬到浏览器里跑

## 容易混淆

- **宽度 vs 深度**：每层神经元多是「宽」，层数多是「深」。宽度决定一层能认多少种模式，深度决定能把简单模式组合成多复杂的特征。同样的参数量，加深通常比加宽更划算
- **参数量 vs 计算量**：参数量只看权重和偏置有多少个，计算量还要乘上训练的样本数和每个样本前向、反向的运算，两者不是一回事
- **sigmoid vs ReLU**：sigmoid 输出在 0 到 1 之间，适合输出层表示概率；ReLU 简单高效，适合隐层，但输入为负时输出恒为 0，可能出现「死神经元」

## 关联

- [[反向传播算法]]：训练神经网络的核心算法，负责算出每个权重该怎么调
- [[交叉熵]]：分类任务最常配的损失函数，衡量「预测的概率分布和真实标签差多远」

## 扩展思考

- **为什么必须有非线性激活？** 两个线性变换复合还是线性变换（矩阵乘矩阵还是矩阵），多层等于一层，白堆了。插入非线性之后每多一层才真正多一层表达能力。
- **为什么只有第一层权重能画成图？** 第一层直接接收原始像素，每个神经元的权重排成 28×28 就是它在匹配的图案。第二层的输入已经是第一层的激活值，不再是像素，画出来就看不出什么了。
