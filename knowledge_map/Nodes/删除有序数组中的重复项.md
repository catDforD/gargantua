# 删除有序数组中的重复项

> LeetCode 26 · 简单：原地删除非递减数组中的重复元素，使每个元素只出现一次，返回新长度。

## 题意要点

- **输入输出**：非递减数组 `nums`，原地去重后返回新长度，结果保持非递减
- **约束**：O(1) 额外空间；`1 <= nums.length <= 3 * 10^4`；新长度之外的内容不作要求
- **示例**：`[1,1,2]` → 2（`[1,2]`）；`[0,0,1,1,1,2,2,3,3,4]` → 5
- **官方标签**：Array、Two Pointers

## 关键观察

数组有序，重复元素必然相邻。所以只要把 `nums[fast]` 和已写区间的最后一个元素 `nums[slow - 1]` 比较，就能判断是不是重复，不需要哈希表。

## 解法

### 解法一：快慢指针（时间 O(n)，空间 O(1)）

- **初始化**：`slow = 1`，第一个元素一定保留
- **扫描**：`fast` 从 1 开始，`nums[fast] != nums[slow - 1]` 时写入 `nums[slow]` 并 `slow++`
- **返回**：`slow`

## 易错点

- **比较对象**：和 `nums[slow - 1]` 比，直接用 `nums[slow]` 会错位
- **空数组**：需要单独返回 0
- **不必清零**：新长度之外的元素不用处理
