# 数组串联

> 数组串联（LeetCode 1929，简单）指给定长度 `n` 的整数数组 `nums`，构造长度 `2n` 的数组 `ans`，满足 `ans[i] == nums[i]` 且 `ans[i + n] == nums[i]`（`0 <= i < n`）。

## 展开

- 题面与约束（LeetCode 官方页）：`nums=[1,2,1]` → `[1,2,1,1,2,1]`。`1 <= n <= 1000`。
- 官方 topic tags：Array、Simulation。
- **按下标映射填两遍**：新建长度 `2n` 的数组，`ans[i] = nums[i]`、`ans[i + n] = nums[i]`，一次遍历完成。时间 O(n)、空间 O(n)（输出本身占 O(n)，无法避免）。
- 语言便利写法：Python `nums * 2`、JS `nums.concat(nums)`，语义等价；面试时能说清底层仍是一次 O(n) 拷贝即可。
- 考察：读题与下标映射，属于热身的模拟题。
