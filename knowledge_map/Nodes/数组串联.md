# 数组串联

> LeetCode 1929 · 简单：把长度 `n` 的数组首尾相接，构造长度 `2n` 的数组。

## 题意要点

- **输入输出**：给定 `nums`，返回 `ans`，满足 `ans[i] == nums[i]` 且 `ans[i + n] == nums[i]`（`0 <= i < n`）
- **约束**：`1 <= n <= 1000`
- **示例**：`[1,2,1]` → `[1,2,1,1,2,1]`
- **官方标签**：Array、Simulation

## 关键观察

这是一道读题和下标映射的热身题：每个 `nums[i]` 在答案里出现两次，位置分别是 `i` 和 `i + n`。

## 解法

### 解法一：下标映射（时间 O(n)，空间 O(n)）

- **做法**：新建长度 `2n` 的数组，一次遍历同时写 `ans[i]` 和 `ans[i + n]`
- **空间**：输出本身就占 O(n)，无法避免

### 解法二：语言内置（时间 O(n)，空间 O(n)）

- **写法**：Python 的 `nums * 2`、JS 的 `nums.concat(nums)`，语义等价
- **面试时**：说清底层仍是一次 O(n) 拷贝即可
