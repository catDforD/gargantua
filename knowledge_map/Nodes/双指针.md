# 双指针

> 在同一个序列上用两个下标同向或相向移动，把暴力枚举的 O(n²) 降到 O(n) 的技巧。

## 核心思想

两个指针把序列分成「已处理」和「待处理」两段，或者利用有序性从两端收缩，每个元素只需要看一次。同向快慢指针负责原地过滤与去重，相向左右指针负责在有序区间上收缩搜索范围。

## 常见套路

- **同向快慢指针**：慢指针指向已写区间的下一个位置，快指针遍历整个数组。删除类题目的骨架是 `if (nums[fast] != val) nums[slow++] = nums[fast]`，最后返回 `slow`。例题见 [[移除元素]]、[[删除有序数组中的重复项]]
- **反向写指针**：目标数组尾部是空位（或可以覆盖）时从后往前填，避免覆盖还没处理的元素。[[合并两个有序数组]] 的三指针就从 `m + n - 1` 往前写
- **相向左右指针**：一般要求序列有序，靠「两数之和偏大就右指针左移、偏小就左指针右移」的单调性剪枝

## 易错点

- **循环条件**：看快指针是否越界（`fast < n`），不是看慢指针
- **返回值**：返回新长度，不是原长度
- **内置函数不算原地**：`erase` / `filter` 会额外分配或搬移元素，不算 O(1) 空间的原地解法

## 本库题目

- [[移除元素]]：快慢指针原地删除，顺序可变时可用相向指针
- [[删除有序数组中的重复项]]：快慢指针，和已写区间最后一个元素比较
- [[合并两个有序数组]]：三指针从后往前写
