# 交叉熵

> 用模型分布编码真实数据的平均比特数，等于熵加分布差距，是最常用的分类与语言建模损失。

## 为什么需要

最大似然估计要求最大化数据在模型下的似然，但连乘会数值下溢，取对数后又只剩一个缺乏直觉的表达式。交叉熵把两件事统一起来：它既是负对数似然的平均，也是「用模型分布编码真实数据需要多少比特」，形式简单、梯度干净，成为分类和语言建模的默认损失。

## 核心要点

- **定义**：`H(p, q) = -Σ p(x)·log q(x)`，`p` 是真实分布，`q` 是模型预测
- **分类损失的来历**：标签 one-hot 时只有真实类别那一项非零，`H(p, q) = -log q(y_true)`，退化为负对数似然；PyTorch 的 `CrossEntropyLoss` 等价于 `LogSoftmax` 加 `NLLLoss`
- **下界**：`H(p, q) ≥ H(p)`，当且仅当 `q = p` 时取等，多出来的部分就是 [[KL 散度]]
- **梯度形式**：softmax 输出配交叉熵，对 logits 的梯度是 `q − p`，不会像 MSE 配 sigmoid 那样在饱和区梯度消失
- **与困惑度**：语言模型逐 token 交叉熵的指数就是困惑度，可以读成「模型在每一步平均在多少个候选之间犹豫」
- **软标签也能用**：知识蒸馏里 `p` 是教师的完整分布，交叉熵让学生对齐教师的概率分布而不只是对齐那个正确答案，教师分布里的暗知识也一并传递

## 容易混淆

- **交叉熵 vs KL 散度**：`H(p, q) = H(p) + D_KL(p‖q)`；`p` 固定时 `H(p)` 是常数，所以最小化交叉熵与最小化 KL 是同一件事，只是前者数值里含数据本身的不确定性
- **交叉熵 vs 负对数似然**：one-hot 标签下数值相同，但交叉熵允许 `p` 是任意软分布，负对数似然一般特指真实标签那一项
- **交叉熵 vs MSE**：分类任务用 MSE 会在输出饱和时梯度消失，交叉熵的梯度与误差 `q − p` 成正比，这也是二者收敛速度差异的来源

## 关联

- [[信息熵]]：`H(p)` 是交叉熵在 `q = p` 时取到的下界，也是交叉熵减去分布差距后的剩余部分
- [[KL 散度]]：交叉熵与熵之差，单独衡量模型分布偏离真实分布多少

## 扩展思考

- **为什么最小化交叉熵等价于最大似然？** 样本上的平均负对数似然就是交叉熵的经验估计，最小化它对参数做优化，与极大化似然完全同解。
- **标签平滑为什么有效？** 把 one-hot 换成 `(1−ε)` 与 `ε/(K−1)` 的混合，等价于给交叉熵加了一项分布熵约束，抑制模型对训练标签过度自信。
